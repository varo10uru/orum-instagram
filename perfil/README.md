# Perfil de ORUM en Instagram y Facebook

Las imágenes se generan con `node scripts/perfil.mjs`. Para ver cómo queda
todo junto, abrí `perfil/vista-previa.html` en Chrome.

## Instagram (@orum.uy)

Se carga desde la app: tu perfil → **Editar perfil**.

| Campo | Qué va |
|---|---|
| Foto | `foto-perfil.png` (el logo oficial; Instagram lo recorta en círculo) |
| Nombre | `ORUM · Sitios web a medida` (aparece en las búsquedas) |
| Categoría | Diseñador de sitios web |
| Bio | El texto de abajo (máximo 150 caracteres) |
| Links | `https://wa.me/59891541848`, con el título "WhatsApp". Cuando el sitio esté publicado, se suma como segundo link |
| Botón de contacto | WhatsApp, 091 541 848 (Editar perfil → Opciones de contacto) |

Bio:

```
Sitios web para comercios y pymes de la Costa.
Hablás directo conmigo, de principio a fin.
Escribime por WhatsApp 👇
```

### Destacadas

Se arman con historias ya publicadas: una historia → "Destacar" → elegís
la destacada y la portada (`destacada-<tema>.jpg`).

| Destacada | Portada | Qué historias van |
|---|---|---|
| Trabajos | `destacada-trabajos.jpg` | Las de la barraca (pilar trabajos) |
| Consejos | `destacada-consejos.jpg` | Las de consejos |
| Cómo trabajo | `destacada-proceso.jpg` | Detrás de escena, el render 3D |
| Contacto | `destacada-contacto.jpg` | La invitación a escribir por WhatsApp |

### Publicaciones fijadas

Fijá arriba del perfil (en el post → ⋯ → Fijar en el perfil):
- el de la barraca;
- el carrusel "3 cosas para que te escriban".
